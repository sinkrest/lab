Pin + progress

A tall section with a sticky full-screen child. Vertical scroll becomes a 0→1 timeline you can map to anything.

Transform only

Animate transform and opacity — they run on the GPU compositor and never trigger layout, so it stays at 60fps.

Lerp smoothing

Instead of using raw scroll, chase it: value += (target − value) × 0.1. That lag is the “buttery” feel.

Easing curves

Linear mapping feels robotic. Pipe progress through cubic ease-in-out and motion gets weight and intent.

How pages like this are built

Everything you just scrolled through is ~300 lines of vanilla CSS + JS in this one file. View source — every scene is commented. The same ideas power award-winning sites, usually via the libraries below.

1 · Scroll = timeline

The whole genre is one idea: read scroll position, normalize it to a number between 0 and 1, and use that number to set transform values every frame via requestAnimationFrame.

2 · Pinning

Make a section 300–400vh tall and give it a position: sticky full-screen child. The visual holds still while the scrollbar keeps moving — that captured distance is your animation timeline.

3 · GPU properties

Only animate transform (translate/scale/rotate) and opacity. Animating width, top or margins forces layout every frame and stutters.

4 · GSAP ScrollTrigger

The industry workhorse. Pinning, scrubbing, snapping and timeline sequencing in a few lines — most Awwwards sites use it instead of hand-rolling the math.

5 · Lenis / smooth scroll

Libraries like Lenis replace the browser's stepped wheel scrolling with an interpolated one, so every scrubbed animation glides instead of ticking.

6 · Three.js for true 3D

The “3D imagery in motion” look — models that assemble, exploded products, camera fly-throughs — is WebGL via Three.js, with scroll driving the camera or a THREE.AnimationMixer timeline.

7 · Morphing

Shapes “becoming something else” = interpolating SVG path points (Flubber, GSAP MorphSVG) or blending WebGL shader uniforms between two geometries.

8 · CSS-only future

The new animation-timeline: scroll() / view() CSS API does scroll-scrubbed keyframes with zero JavaScript — already shipped in Chrome and Edge.
